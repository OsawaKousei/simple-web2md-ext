# Web to Markdown 1.1

ウェブページを Markdown ファイルに保存するブラウザ拡張機能です。

## 更新内容

- 依存ライブラリとビルド環境を更新しました。
- 保存処理をブラウザ標準のダウンロード方式に変更し、不要な `downloads` 権限を削除しました。
- Safari 向けの Mac アプリを追加しました。Intel／Apple Silicon の両方に対応し、Developer ID による署名と Apple の公証を実施しています。
- Mac アプリから Safari の拡張設定を開く処理で、参照する拡張機能 ID を修正しました。

## ダウンロード

ページ下部の Assets から、利用する環境に合ったファイルをダウンロードしてください。

| 対象                                        | ファイル                                        |
| ------------------------------------------- | ----------------------------------------------- |
| Chrome / Microsoft Edge                     | `simple-web2md-ext-1.1-chrome-edge.zip`         |
| Chrome の署名済みパッケージ（ストア提出用） | `simple-web2md-ext-1.1-chrome.crx`              |
| Firefox                                     | `simple-web2md-ext-1.1-firefox.zip`             |
| Firefox のビルド用ソース                    | `simple-web2md-ext-1.1-firefox-source.zip`      |
| Safari（macOS）：インストール用 DMG         | `WebToMarkdown-1.0.0-2494.16.15-github.dmg`     |
| Safari（macOS）：アプリ本体の ZIP           | `WebToMarkdown-1.0.0-2494.16.15-github.app.zip` |
| SHA-256 チェックサム                        | `SHA256SUMS`                                    |

Chrome / Edge / Firefox の拡張バージョンは **1.1** です。
今回同梱する Safari 用 Mac アプリの内部バージョンは **1.0.0（ビルド 2494.16.15）** で、ファイル名にもこの値を使用しています。

## インストール

### Chrome / Microsoft Edge

ZIP を展開し、`chrome://extensions/` または `edge://extensions/` でデベロッパーモードを有効にして、「パッケージ化されていない拡張機能を読み込む」から展開先を選択します。

通常の利用では、[Chrome Web Store](https://chromewebstore.google.com/detail/web-to-markdown/kpobgdndklphhmkkjloefgmenidljpdh) または [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/web-to-markdown/fnadejhpnenfeejgcbfcoiepbiimpjon) からインストールできます。ストア版への更新反映は各ストアの審査・公開後になります。

### Firefox

通常の利用では [Mozilla Add-ons](https://addons.mozilla.org/firefox/addon/web-to-markdown-extension/) からインストールしてください。ストア版への更新反映は審査・公開後になります。

添付の Firefox ZIP は署名前のパッケージです。動作確認には ZIP を展開し、`about:debugging#/runtime/this-firefox` の「一時的なアドオンを読み込む」から `manifest.json` を選択してください。

### Safari（macOS 13 以降）

DMG を開いてアプリを Applications に移動するか、アプリ本体の ZIP を展開して Applications に配置します。
アプリを起動し、Safari の「設定 → 機能拡張」で Web to Markdown を有効にしてください。

保存したいウェブページを開き、機能拡張を実行すると `.md` ファイルを保存します。

## ソースとチェックサム

Firefox の再現ビルド用ソース ZIP には、元の TypeScript、依存関係のロックファイル、ビルド手順を含めています。
提出用 Firefox ZIP と、ソース ZIP から再ビルドした全ファイルの内容が一致することを確認しています。

ダウンロード後のファイルを検証する場合は、同じフォルダーに全添付ファイルと `SHA256SUMS` を置き、次を実行してください。

```sh
# macOS
shasum -a 256 -c SHA256SUMS

# Linux
sha256sum -c SHA256SUMS
```
