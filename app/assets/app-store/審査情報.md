## macOS の審査メモ

```text
Web to Markdownは、Safariで表示中のウェブページをMarkdownファイルとして保存するSafari機能拡張です。アプリ本体は、機能拡張の有効化を案内する画面です。

確認手順
1. アプリを起動し、有効化の案内を確認してください。
2. Safariの「設定」→「機能拡張」でWeb to Markdownを有効にしてください。
3. ログイン不要の記事ページをSafariで開いてください。
4. SafariのツールバーからWeb to Markdownを実行してください。サイトへのアクセス許可を求められた場合は許可してください。
5. ページタイトルをもとにした名前の.mdファイルが、Safariで設定されたダウンロード先に保存されることを確認してください。ファイル名に使用できない文字は置き換えます。

アカウント登録、ログイン、課金は不要です。処理は端末内で行い、ページ内容や変換結果を開発者のサーバーへ送信しません。
Safariの内部画面などでは実行できません。ページの構造によっては記事本文の一部を抽出できない場合があります。
```

Video: https://drive.google.com/file/d/1yH2cv8wUxGYxUiAmf8luwHDkm8pAEIon/view?usp=sharing

2. Purpose and audience
Web to Markdown is a Safari Web Extension for people who want editable notes from web articles, including students, researchers, and writers. It extracts the current page's text and converts headings, lists, links, and image references into a .md file. Images remain URL references; image files are not bundled. It is a general consumer utility with no organization membership requirement.

3. Setup and review steps
The containing app displays setup instructions. The main feature runs inside Safari; there is no separate editor or conversion screen in the containing app.
a. Launch Web to Markdown.
b. Open Settings > Apps > Safari > Extensions > Web to Markdown and enable the extension. On older OS versions, Safari is directly under Settings.
c. Open our public sample page https://web2md.prj.kupac.co.jp/ in Safari. No account or sample-file import is required.
d. Open Safari's page/extension menu, select Web to Markdown, and grant access to this website if prompted. Run it again after permission is granted if necessary.
e. If Safari prompts, tap Download. Open the .md file from Safari's Downloads list or the Files app. Its preview displays the generated Markdown text.
Expected result: a non-empty .md file named from the page title, with the article text and Markdown formatting. Safari's download location setting determines where it is saved.
Safari internal pages are unsupported; extraction can vary by webpage structure.

No account creation, login, account deletion flow, in-app purchases, or paid features are present. There is no in-app community or user-to-user publishing, so reporting and blocking flows do not apply.

No developer backend, authentication, payment, AI, advertising, or analytics service is used for conversion. Page content and generated Markdown are not sent to developer servers. Loading the source website uses normal web traffic. The download location may be iCloud Drive if selected in Safari; no iCloud account is required by this app.

5. Regional behavior
The app has no region-based feature or content variations. Store availability is separate from functionality. Access to source websites depends on those sites and local connectivity.

6. Regulated services and protected material
This is a general-purpose local conversion utility, not a regulated-industry service. It has no developer-provided third-party content catalog or media streaming feature. Users choose the webpage to convert; the app does not bypass login or paywalls. The demonstration uses our own public product website. Bundled open-source license notices are included in NOTICE.md.
