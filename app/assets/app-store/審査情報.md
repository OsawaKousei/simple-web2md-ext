# App Review 情報

審査情報欄への入力用です。審査メモには OS ごとのコードブロック内の文章を貼り付けます。

## 連絡先

| 項目     | 入力値                                                        |
| -------- | ------------------------------------------------------------- |
| 名       | 要入力：審査に対応する担当者の名                              |
| 姓       | 要入力：審査に対応する担当者の姓                              |
| メール   | `dev@kupac.co.jp`                                             |
| 電話番号 | 要入力：担当者へ連絡できる国際形式の番号（日本は `+81` から） |

担当者名と電話番号は公開資料から確認できないため、提出前に入力してください。

## サインイン情報

「サインインが必要」はオフにします。テスト用アカウントは不要です。

## macOS の審査メモ

```text
Web to Markdownは、Safariで表示中のウェブページをMarkdownファイルとして保存するSafari機能拡張です。アプリ本体は、機能拡張の有効化を案内する画面です。

確認手順
1. アプリを起動し、有効化の案内を確認してください。
2. Safariの「設定」→「機能拡張」でWeb to Markdownを有効にしてください。
3. ログイン不要の記事ページをSafariで開いてください。
4. SafariのツールバーからWeb to Markdownを実行してください。サイトへのアクセス許可を求められた場合は許可してください。
5. ページタイトルをもとにした名前の.mdファイルが、Safariで設定されたダウンロード先に保存されることを確認してください。ファイル名に使用できない文字は置き換えます。

アカウント登録、ログイン、課金は不要です。処理は端末内で行い、ページ内容や変換結果を開発者のサーバーへ送信しません。
Safariの内部画面などでは実行できません。ページの構造によっては記事本文の一部を抽出できない場合があります。
```

## iOS の審査メモ

```text
Web to Markdownは、Safariで表示中のウェブページをMarkdownファイルとして保存するSafari機能拡張です。iPhoneとiPadに対応しています。アプリ本体は、機能拡張の有効化を案内する画面です。

確認手順
1. アプリを起動し、有効化の案内を確認してください。
2. 設定アプリの「アプリ」→「Safari」→「機能拡張」からWeb to Markdownを有効にしてください。OSのバージョンによっては「設定」→「Safari」→「機能拡張」にあります。
3. ログイン不要の記事ページをSafariで開いてください。
4. Safariの機能拡張メニューからWeb to Markdownを実行してください。サイトへのアクセス許可を求められた場合は許可してください。
5. Safariのダウンロード一覧またはファイルアプリで、ページタイトルをもとにした名前の.mdファイルが保存されていることを確認してください。保存先はSafariのダウンロード設定に従います。

アカウント登録、ログイン、課金は不要です。処理は端末内で行い、ページ内容や変換結果を開発者のサーバーへ送信しません。
Safariの内部画面などでは実行できません。ページの構造によっては記事本文の一部を抽出できない場合があります。
```

## 提出前に残っている作業

- 担当者名・電話番号を入力し、メールが受信可能であることを確認する。
- Mac・iPhone・iPad で有効化から保存までの手順を実際に確認する。
- スクリーンショットを撮影し、各対象の掲載欄へ登録する。
- 各 OS でバージョン `1.0.0`、ビルド `2494.13.55` を選択する。
- 年齢制限指定や輸出コンプライアンス等、画面に表示される質問に実装に沿って回答する。
