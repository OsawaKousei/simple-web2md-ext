## 説明

```text
Safariで開いているウェブページを、Markdown形式のファイルとして保存できる拡張機能です。調べもののメモや、後で編集したい記事の保存に使えます。

記事の本文を抽出し、見出し、段落、リンク、画像の参照をMarkdownに変換します。変換結果はページタイトルをもとにした名前の.mdファイルとして保存します。画像そのものはファイルに同梱せず、元の画像へのリンクとして残します。

使い方
1. インストール後、Safariの設定でWeb to Markdownの機能拡張を有効にします。
2. 保存したいページをSafariで開きます。
3. Safariのツールバーまたは機能拡張メニューからWeb to Markdownを実行します。サイトへのアクセス許可を求められた場合は許可してください。

ページの変換は端末内で行います。ページ内容や変換結果を開発者のサーバーへ送信しません。アカウント登録は不要です。

Mac、iPhone、iPadのSafariに対応しています。ページの構造によっては、一部の内容を正しく抽出できない場合があります。Safariの内部画面など、拡張機能の実行が許可されていないページでは利用できません。
```

## スクリーンショット

審査提出にはスクリーンショットが必要です。Mac アプリは Mac 用を最低 1 枚登録します。
ヘッダ画像の登録だけでは、この要件を満たしません。

Mac アプリと iOS シミュレーターで実際のアプリを起動し、有効化の案内画面を取得しました。
取得した実画面は案内画面です。Safari での変換操作・保存結果の実画面は追加撮影が必要です。

Mac 向けには、既存 creative の雰囲気に合わせた説明付き静止画像も用意しています（各 2560×1600 PNG）。

- [実際のアプリ画面と保存手順](screenshots/mac-02-how-to-ja.png)
- [記事から Markdown への変換例](screenshots/mac-01-markdown-ja.png)（図解）

これらも「Mac → アプリスクリーンショット」に登録します。「アプリプレビュー」は動画用です。

| 対象           | 撮影済み画像                                                                        | 追加撮影する内容                                                              |
| -------------- | ----------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| Mac            | [有効化の案内画面](screenshots/mac-onboarding.jpg)（2560×1600）                     | Safari で機能拡張を実行する場面と、保存した Markdown の内容が分かる画面       |
| iPhone（中型） | [有効化の案内画面](screenshots/iphone-medium-onboarding-1206x2622.jpg)（1206×2622） | Safari の機能拡張メニューから保存する場面、または保存したファイルが分かる画面 |

現在の iOS ビルドは iPhone・iPad の両方を対象にしているため、iPad 用も準備します。
6.1／6.3 インチの「Dynamic Island 搭載 iPhone（中型ディスプレイ）」欄には中型用を登録してください。大型用の画像は、この欄ではサイズエラーになります。
各対象で少なくとも 1 枚を用意し、App Store Connect が要求するサイズに合わせます。
`../store-screenshot.png` は変換例を説明するための参考資料です。Apple 向けの実画面は別途撮影します。
