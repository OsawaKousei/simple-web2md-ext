# App Store のプライバシー情報

macOS・iOS 共通です。現在の実装と既存のプライバシーポリシーに基づく入力内容です。

## プライバシーポリシー URL

```text
https://web2md.prj.kupac.co.jp/privacy/
```

公開前にリンク先を開けることを確認してください。

## データ収集に関する回答

「あなた、またはサードパーティパートナーは、このアプリからデータを収集しますか？」に相当する質問では、次の回答を選択します。

```text
いいえ、このアプリからデータを収集しません。
```

この回答を保存し、「公開」を押してプライバシー情報を確定します。

## 回答の根拠

- ユーザーが変換を指示したページの本文、タイトル、URL を端末内で一時的に処理します。
- 変換結果はユーザーの端末に Markdown ファイルとして保存します。
- ページ内容、URL、変換結果を開発者や第三者のサーバーへ送信しません。
- 広告・アクセス解析・追跡用の SDK を組み込んでいません。
- アカウント作成やログインは不要です。

ユーザーが製品ページの問い合わせフォームを使う場合の情報は、同ページのポリシーに従います。アプリ内で問い合わせ情報を収集する機能はありません。
