# パッケージのタイトル

Web to Markdown

# パッケージの概要

開いているウェブページをワンクリックでMarkdownファイルに保存します。

# 説明

Web to Markdownは、閲覧中のウェブページをMarkdown形式のテキストファイルとして保存するブラウザ拡張機能です。記事の本文を抽出してMarkdownに変換し、ページタイトルを使った `.md` ファイルをダウンロードします。

使い方は、保存したいページを開いてツールバーのアイコンをクリックするだけです。見出し、段落、リンク、画像などをMarkdownに変換し、相対URLは元のページを基準とする絶対URLにします。記事本文を抽出できない場合は、ページ本文から変換を試みます。

調べもののメモや、後で編集したい記事の保存に利用できます。ページの内容はブラウザ内で処理され、変換結果はローカルのダウンロードフォルダーに保存されます。

Chrome、Edge、Firefoxに対応しています。ブラウザの内部ページなど、拡張機能によるスクリプト実行が許可されていないページでは利用できません。また、ページの構造によっては、内容の一部を正しく抽出できない場合があります。
